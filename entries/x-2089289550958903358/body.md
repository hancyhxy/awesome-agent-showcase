A web page with a paper receipt that you tear off by dragging it with the mouse or a finger. Drag slowly and the paper tears along a clean, even line. Drag fast and the edge comes out jagged. Atu builds it with plain HTML, CSS and JavaScript in a new folder, then opens it in your browser.

- The video is an iPhone concept: the receipt prints out of the Dynamic Island. Atu builds a web page, so there is no Dynamic Island.
