## What you get

A Claude Code Desktop theme in your own colours, with an animated backdrop if you want one, such as the synthwave sunset in the video. Atu writes it as a mod in a new folder and shows you the files first.

## Good to know

- Themes work in local sessions of Claude Code Desktop. Cloud sessions are not supported yet.
- A mod is code that runs with your permissions. Read it before you load it. The [mods overview](https://code.claude.com/docs/en/plugins/mods/overview) says how to check one.
